# copilot_skills
Copilot Skills

## Skills

- [TDD and Ralph Development Loop](.github/skills/tdd-ralph-loop/SKILL.md):
  coordinates test-first Red-Green-Refactor with a fresh worktree and branch
  per iteration, merged into the base after verification.

## Agents

- [Ralph Loop](.github/agents/ralph-loop.agent.md): performs one focused
  development iteration in a fresh worktree and branch, then merges it into
  the base branch using the TDD and Ralph loop skill.
